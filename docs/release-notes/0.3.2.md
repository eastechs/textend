# Textend 0.3.2

- Improved keyword expansion responsiveness after sleep and when switching apps, with safeguards against delayed input replacing the wrong text.
- Prevented temporary iCloud availability changes from turning off sync. Actual sign-outs and account changes still preserve your library separately.
- Corrected the iCloud sync switch to show your saved choice. If iCloud was unavailable when Textend opened, Settings keeps sync enabled and offers a restart once the same account is available.

If you use iCloud sync, update Textend on every Mac before using app-specific collections. Older versions cannot enforce app restrictions or display Compositions.
